# Phase 17 classification contract

This phase is limited to the **Xiaomi Mi AIoT AX6000, model RA72**, based on
Qualcomm IPQ5018 and board configuration MP03.1.

It classifies public DD-WRT source-path signals into:

- exact RA72 / Mi AIoT AX6000 signals;
- IPQ5018 build or profile candidates;
- kernel and Device Tree candidates;
- driver-only candidates.

The audit does not build firmware, access a router, or produce a flashable file.
Names and path matches are evidence for further review only.
